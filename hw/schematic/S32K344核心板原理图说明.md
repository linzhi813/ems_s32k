### 内部 DC-DC 控制引脚
| 引脚 | 功能 |
|------|------|
| PTA27 / VDD_DCDC | DC-DC 电源输入 |
| PTE14 / VSS_DCDC | DC-DC 地 |
| PTE13 / VRC_CTRL | DC-DC 控制 |
| PTE3 / PMOS_CTRL | PMOS 控制 |

### 型号选择电阻（S32K3 系列兼容）
该核心板兼容 S32K312 / S32K344 / S32K358 三款器件，通过 R10~R17 选择电源拓扑：

| 器件型号 | 焊接电阻 |
|----------|----------|
| S32K312 | R10 |
| **S32K344** | **R11、R12、R13、R14**（0 Ω） |
| S32K358 | R11、R12、R13、R14、R15、R16、R17 |

**取消焊接（Deselector）规则：**
- S32K312：拆除 R11（必须）、R12、R13、R14、R15、R16、R17
- S32K344：拆除 R10（必须）、R15、R16、R17
- S32K358：拆除 R10（必须）

默认按 S32K344 焊接（R11~R14 = 0 Ω，R10/R15~R17 = NC）。

## Sheet 5：排针引出

核心板通过 4 组 **PZ254-2-18-Z-8.5**（2.54mm 间距 2×18 排针，共 36 脚/组）引出全部 GPIO：

| 排针 | 引出端口 |
|------|----------|
| H4 | Port A / B 部分引脚 |
| H8 | Port C / D 部分引脚 |
| H12 | Port E / B 部分引脚 |
| H14 | Port D / C 部分引脚 |
